# SmileCare Agent — programmes d'installation

Ce dépôt ne contient aucun code : il héberge les programmes d'installation de l'agent SmileCare,
le petit programme qui relie un poste du cabinet à SmileCare (scanner, radiologie, carte Vitale, NFC).

**Pour installer ou mettre à jour l'agent, passez par SmileCare** : Mon compte › Ce poste › Télécharger.
Le programme s'installe pour l'utilisateur Windows courant, sans droits d'administrateur ; relancer une
version plus récente par-dessus met à jour l'agent sans perdre sa configuration.

Chaque version publie l'empreinte SHA-256 de son programme d'installation (dans ses notes et dans
`SHA256SUMS.txt`) : c'est la même que celle affichée dans « Ce poste ».
